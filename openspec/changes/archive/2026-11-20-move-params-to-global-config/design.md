# Design

## Context

Форк `@biorate/hygen@0.10.0` поддерживает два места декларации параметров:

- **глобально** — член `params` в проектном конфиге (`.hygen.ts`): движок резолвит схему в `engine.js` сразу после определения генератора, **до разбора действия**;
- **на действие** — `static params` / instance-`params` в hook-классе (instance выигрывает при обоих).

## Goals / Non-Goals

**Goals:**

- Декларативная схема параметров в классовой форме хуков без legacy-форм `hooks.js`.
- Нулевое изменение наблюдаемого поведения генерации, включая `hygen create help`.

**Non-Goals:**

- Глобальная схема в конфиге — проверена на практике и отклонена (см. D1).
- Разделение схемы по действиям, изменение `argCase`, guard'ов, логики `afterAll`.

## Decisions

**D1: Глобальный `params` в `.hygen.ts` — отклонён.**
Промптится движком до запуска действий безусловно (`engine.js`: `if (config.params?.length)`), поэтому `hygen create help` требовал `--root` и иные параметры — мета-действие CLI ломается. Обход в форке (`generator !== 'help'`) возможен, но решение в пользу per-action хуков: не требует релиза форка и сохраняет семантику «параметры принадлежат действию».

**D2: Схема — instance-свойство `params` в hook-классах (вместо `static params`).**
Движок читает `instance.params ?? staticParams`; instance-форма — целевой способ форка 0.10.0 и позволяет в будущем переопределять схему в конструкторе. Три hook-файла содержат одинаковую схему — дублирование остаётся, это осознанный trade-off против ломки `help`.

**D3: Тесты проверяют instance-форму и отсутствие схемы в конфиге.**
`tests/factory.spec.ts`: дескрипторы instance-`params` всех трёх хуков; `'params' in project === false` для фабрики.

## Risks / Trade-offs

- [Схема дублируется в трёх hook-файлах] → осознанно: дедупликация через конфиг ломает `help`; вариант с правкой форка отложен.
- [Путаница static/instance у будущих контрибьюторов] → тест `hooks-instance-params` фиксирует форму; sync между файлами не критичен (схемы идентичны).

## Migration Plan

1. Убрать глобальный `params` из `.hygen.ts` (эксперимент в рамках change).
2. В трёх `hooks.ts` заменить `static params` на instance `params`.
3. Обновить тесты, прогнать `pnpm test`.
4. Откат — git revert.

## Open Questions
