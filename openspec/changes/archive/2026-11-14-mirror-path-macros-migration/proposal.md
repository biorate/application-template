# Proposal

## Why

Каждый из ~180 шаблонов несёт дублирующий фронтматтер `to: <%= ... путь ... %>`, который повторяет собственное расположение файла в дереве `_templates/` с подстановкой `h.ROOT`/`h.CLIENT_NAME`/`h.SERVER_NAME`. В `@biorate/hygen@0.2.0` появились path macros (`$IDENTIFIER$` в именах папок зеркалируемых целей) и conditional skip (`skip:`) — теперь путь записи можно выводить из расположения самого шаблона, а `to:` убрать по максимуму. Апдейт до 0.2.0 уже выполнен, мигрировать удобно сейчас.

## What Changes

- Пути-шаблоны папок: каталоги внутри действий переименованы под макросы — `client/apps/client/**` → `client/apps/$CLIENT_NAME$/**`, `server/apps/server/**` → `server/apps/$SERVER_NAME$/**`; root-шаблоны вкладываются в `_templates/create/root/$ROOT$/**`.
- Фронтматтер `to:` удаляется из всех шаблонов, путь которых выводим из расположения (~147 файлов); вместо него — `mirror: true` (цель = относительный путь шаблона с подстановкой `$ROOT$`/`$CLIENT_NAME$`/`$SERVER_NAME$`, суффикс `.t` срезается).
- Условная генерация (33 шаблона с `h.CLIENT &&`, `h.SERVER &&`, `!h.CUT_EXAMPLES &&`, `h.ADD_WEB_SOCKET &&` в `to:`) переводится на атрибут `skip:` с причиной пропуска; условный `to:` исчезает.
- Шаблоны с нетривиальным вычислением пути, если таковые останутся, сохраняют `to:` (принцип «по максимуму», не «всё или ничего»).
- Хелпер `h.root` (identity) удаляется из `.hygen.js` и синхронно из `root/.hygen.js.t`.
- Документация обновляется: правило «путь записи определяется только атрибутом `to:`» в root `AGENTS.md` (и шаблоне `AGENTS.md.t`) заменяется на правила mirror + path macros + `skip:`; при необходимости — `README.md`.
- Поведение генерации не меняется: состав и содержимое сгенерированных файлов идентичны текущим (проверяется golden-фикстурами). **BREAKING**-изменений в командах и флагах нет.

### Modified Capabilities

- `app-generator`: правила вывода целевых путей шаблонов — зеркалирование расположения шаблона (`mirror: true`) с path macros `$IDENTIFIER$` в именах папок вместо явного `to:`; условная генерация файлов через атрибут `skip:` вместо условного `to:`.

## Impact

- `_templates/create/**` — массовое переименование каталогов и правка фронтматтера (~180 файлов).
- `.hygen.js` и `_templates/create/root/.hygen.js.t` — удаление `h.root`, синхронизация.
- `AGENTS.md`, `_templates/create/root/AGENTS.md.t` (и при необходимости `README.md`, `doc/`) — обновление правил шаблонизации.
- `tests/` — ассерты фабрики (при наличии упоминаний `to:`), обязательная регенерация golden-фикстур (`node tests/__fixtures__/generate-manifests.mjs`) и прогон `pnpm test`.
- Зависимости: `@biorate/hygen@0.2.0` (уже обновлена).
