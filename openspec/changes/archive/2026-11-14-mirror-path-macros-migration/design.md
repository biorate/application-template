# Design

## Context

`@biorate/hygen` обновлён до 0.2.0: в fork'е появились path macros (`$IDENTIFIER$` в сегментах зеркалируемых целей, см. `src/path-macros.ts` в core) и conditional skip (`skip:` в фронтматтере). Текущие шаблоны (~180 файлов) несут `to: <%= ... %>`, дублирующий собственное расположение. Детали мотивации и объёма — в proposal.md.

Инвентаризация текущего фронтматтера:

| Категория                | Кол-во | Текущий паттерн `to:`                                                     |
| ------------------------ | ------ | ------------------------------------------------------------------------- |
| Приложения client/server | ~150   | ``<%= `${h.ROOT}/apps/${h.X_NAME}/...` %>``                               |
| Корень (root)            | ~20    | ``<%= h.root(`${h.ROOT}/...`) %>``                                        |
| Условные                 | 33     | `h.CLIENT &&`, `h.SERVER &&`, `!h.CUT_EXAMPLES &&`, `h.ADD_WEB_SOCKET &&` |
| sh:/echo-действия        | 3      | не содержат `to:`                                                         |

`unless_exists: true` (177) ортогонален источнику пути. `inject` как атрибут не используется. `h.root` — identity-хелпер, нужен только условному `to:`.

## Goals / Non-Goals

**Goals:**

- Убрать `to:` из всех шаблонов, чей путь выводим из расположения (target ~147 не-условных + переиспользование макросов в условных).
- Условную генерацию перевести на `skip:` с человекочитаемой причиной.
- Сохранить байт-в-байт результат генерации (golden-фикстуры).

**Non-Goals:**

- Переход на `glob:`-батчи (другая механика, не требуется).
- Изменение `.hygen.js` кроме удаления `h.root` (валидация, guard, флаги — не трогаем).
- Изменение команд, флагов, интерактивных промптов.
- Рефакторинг тел шаблонов (EJS внутри файлов).

## Decisions

1. **Mirror + переименование каталогов, а не `to:` с макросами.** Макросы работают только в зеркалируемых целях; путь = `path.relative(actionfolder, file)` с подстановкой. Каталоги переименовываются: `client/apps/client/**` → `client/apps/$CLIENT_NAME$/**`; `server/apps/server/**` → `server/apps/$SERVER_NAME$/**`; root-шаблоны вкладываются в `_templates/create/root/$ROOT$/**` (иначе относительный путь не даёт префикса цели). Альтернатива — оставить `to:` и ждать поддержки макросов в нём: отклонено, не существует в 0.2.0.
2. **`$ROOT$` как префиксный макрос.** Подстановка — простая строка: значение `h.ROOT` (абсолютный путь) содержит `/`, что легально внутри сегмента. Альтернатива — запуск генерации с `cwd = ROOT` и чисто относительными путями: отклонено, меняет семантику запуска и рискует сломать существующие вызовы `runner()` в тестах.
3. **`skip:` вместо условного `to:`.** Каждому условному шаблону добавляется `skip:` с короткой причиной: `skip: <%= !h.CLIENT && 'client action not requested' %>`, `skip: <%= h.CUT_EXAMPLES && 'examples cut' %>`, `skip: <%= !h.ADD_WEB_SOCKET && 'web socket not requested' %>`. Truthy-результат пропускает действие мягко (не failure). Альтернатива — физическое разнесение файлов по действиям: отклонено — разнесёт логически цельные группы (примеры) по дереву.
4. **`unless_exists` сохраняется во всех шаблонах без изменений** — не зависит от источника пути.
5. **`h.root` удаляется** из `.hygen.js` и синхронно из `_templates/create/root/.hygen.js.t` (правило репо: синхронизация двух фабрик). Остальные хелперы не трогаются.
6. **Порядок миграции: действие за действием** (root → client → server), после каждого — регенерация фикстур и прогон тестов. Откат — `git checkout` группы шаблонов.

## Risks / Trade-offs

- [В процессе изменения `@biorate/hygen` 0.3.0 начала вызывать фабрику хелперов с пустыми locals на бутстрапе, ломая энергичную валидацию] → Исправлено на стороне fork'а в 0.4.0 (`fix(hygen): resolve hook helpers lazily from CLI args`): hook helpers резолвятся лениво из CLI-аргументов; фабрика проекта не требует защитного кода, хак удалён. Проверено: генерация без хака байт-в-байт совпадает с эталоном, тесты зелёные.

- [`$` в именах папок путает shell/инструменты] → Механические операции делать через git mv и IDE; shell-команды с `$` — в одинарных кавычках. Проверить ls-lint/IDE на каталоге после первого переименования.
- [Опечатка в имени макроса даёт fail-fast в рантайме] → Первая же генерация в tmp/ ловит `PathMacroResolutionError` с точным указанием файла; прогон diff-матрицы обязателен до коммита.
- [Расхождение `.hygen.js` и `root/.hygen.js.t`] → Править обе фабрики одним шагом (существующее правило репо).
- [Ассерты фабрики/доков на `to:`] → `factory.spec.ts`, `AGENTS.md*`, `README.md` просмотреть на упоминания `to:`/`h.root` и обновить.
- [Порядок исполнения меняется] → Пути-шаблоны не влияют на порядок (алфавитный по полному пути); переименование `client` → `$CLIENT_NAME$` может сдвинуть алфавитный порядок внутри действия — проверить `z-after.t` остаётся последним, `a-before.t` первым; при необходимости переименовать точки входа.
