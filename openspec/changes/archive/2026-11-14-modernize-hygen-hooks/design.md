# Design

## Context

`@biorate/hygen@0.4.0`: классовые action hooks (`hooks.*`, приоритет над legacy `index.*`/`prompt.*`; дефолт-экспорт класса обязателен, иначе `HookModuleError`), project-level `hooks` (plain object, без prompt-секции), `.hygen.ts`/`hooks.ts` с транспиляцией через `ts-node`. Текущее состояние: 3 идентичных legacy `prompt.js`, мёртвый `minimist` в фабриках, `.hygen.js.t` без frontmatter (никогда не рендерится — фабрика не доставляется в цели, что противоречит AGENTS.md и golden-фикстурам).

## Goals / Non-Goals

**Goals:**

- Перевести prompt-логику на классовую TS-форму `hooks.ts` (дефолт-экспорт класса, async `prompt({ prompter, args })`).
- Перевести фабрику на `.hygen.ts` с именованным экспортом `export const helpers` и доставить её в цели (закрыть расхождение доков и реальности).
- Чистка фабрик; сохранить их синхронность (байт-в-байт, с учётом repo-prettier).
- Починить guard фабрики: ресолв несуществующего `--root` к ближайшему существующему предку перед `realpathSync`.

**Non-Goals:**

- Project-level `hooks` в `.hygen.ts` — нет cross-run состояния и прогоночных логов.
- Перевод копирования `bin/favicon.ico` (`sh: npx fse copy`) на нативные механизмы — отдельная тема.
- Изменение логики prompting (флагов, порядка вопросов) — только форма.

## Decisions

1. **Полный TS («вариант B»): `hooks.ts` + `.hygen.ts`.** Типизация требует `ts-node` — он добавлен в devDeps репозитория (`ts-node@^10.9.2`), а `typescript` даунгрейден `^7.0.2` → `^5.0.4` (ts-node@10.9.2 несовместим с TS7: `TypeError: Cannot read properties of undefined (reading 'fileExists')` на `ts.sys`). В шаблоне цели (`package.json.t`) `ts-node@10.9.2` + `typescript@5.0.4` уже были — у потребителя зависимость присутствует. Самодостаточные минимальные интерфейсы в `hooks.ts`: `@biorate/hygen` не ре-экспортирует типы ActionHooks/Prompter.
2. **Именованный экспорт `export const helpers` в `.hygen.ts` — контракт движка.** `export default` ломает резолв: резолвер спредит namespace модуля; для `.hygen.js` это скрывал cjs-interop (`module.exports` не спредился), ошибка проявлялась как `createPrompter is not a function`. Классовый дефолт-экспорт обязателен только для hook-файлов (`hooks.ts`), не для фабрики.
3. **Три копии `hooks.ts`, по одной на действие.** Hook-модуль резолвится в папке действия, project-level `hooks` prompt-секции не имеет — дедуп между действиями механизмом движка невозможен. Дубликат осознанный и маленький (~20 строк); при желании позже можно вынести тело промпта в общий модуль, импортируемый классом (hook-файлы не рендерятся, импорт валиден).
4. **Фронтматтер для `_templates/create/root/$ROOT$/.hygen.ts.t`: `mirror: true` + `unless_exists: true`.** Файл лежит в `_templates/create/root/$ROOT$/` — зеркалирование даёт путь `<root>/.hygen.ts`. `unless_exists` защищает от затирания фабрики при повторных прогонах. Тело шаблона байт-в-байт синхронно с `.hygen.ts` репозитория (sync-тест в `factory.spec.ts`); для этого оба файла отформатированы repo-prettier (prettier в `z-after.t` переформатирует цель).
5. **Фикс guard'а фабрики.** Несуществующий `--root` разрешён: путь ресолвится к ближайшему существующему предку перед `realpathSync` (раньше падал realpath ENOENT; старые тесты маскировали это грязным /tmp — теперь root тестов = `os.tmpdir()`).
6. **Golden-фикстуры регенерируются**, манифесты дополняются хэшем `.hygen.ts` — единственное изменение вывода; проверка диффа по всем комбинациям действий/флагов как в предыдущем изменении.

## Risks / Trade-offs

- [Требование дефолт-экспорта класса: ошибка в форме (`module.exports.prompt` вместо класса) даёт `HookModuleError` в рантайме] → Миграция проверяется прогоном генерации в TTY-эмуляции и non-TTY; тесты `runner.spec.ts` обновляются и покрывают оба режима.
- [Доставка `.hygen.ts` меняет вывод генерации] → Осознанное изменение, зафиксировано в спеке; манифесты регенерируются, полная diff-матрица прогоняется.
- [`hooks.ts`/`.hygen.ts` в цели требуют `ts-node` у потребителя] → Есть в `package.json.t` цели (`ts-node@10.9.2` + `typescript@5.0.4`).
- [Dynamic `import()` `.ts` на Node 24 работает через type-stripping, на Node 20 возможен `ERR_UNKNOWN_FILE_EXTENSION`] → Движок fork'а лениво регистрирует `ts-node/register/transpile-only` для `.ts`-конфигов и hook-файлов, что снимает риск при установленном ts-node.
- [Повторные прогоны в существующие цели получат существующую фабрику цели (не затирается)] → Желаемое поведение; фабрика цели — собственность потребителя после генерации.
