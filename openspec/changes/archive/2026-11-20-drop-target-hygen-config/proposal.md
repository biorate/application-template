# Proposal

## Why

Действие `root` доставляет фабрику хелперов `.hygen.ts` в сгенерированную цель (`.hygen.ts.t`, `mirror: true` + `unless_exists: true`), но генерация всегда выполняется из репозитория-шаблона, чей корневой `.hygen.ts` и есть конфиг движка: шаблоны никогда не запускаются из цели, поэтому доставленная копия — мёртвый артефакт, а `unless_exists`-защита от перетирания решает несуществующую проблему. Доставленный файл требует байт-в-байт синхронизации с корневым при каждой правке — постоянная накладная нагрузка без пользы.

## What Changes

- Удалён шаблон `_templates/create/root/$ROOT$/.hygen.ts.t` — `.hygen.ts` больше не доставляется в сгенерированную цель.
- Dep `@biorate/hygen` в `package.json.t` цели **сохраняется**: через него планируется догенерация шаблонов в цели.
- `.hygen.ts` репозитория-шаблона остаётся единственной фабрикой хелперов (конфиг движка, createPrompter, guard, валидация) — без изменений.
- Обновлены требования спеки `app-generator`: требование доставки фабрики в цель удаляется, требования «Чистота фабрики хелперов», «Сохранение генерируемого результата» и «Неинтерактивный режим» переписаны без упоминания шаблона доставки.
- Документация (`AGENTS.md`) синхронизирована: описания `.hygen.ts` и правила синхронизации пары файлов убраны/упрощены.
- Golden-фикстуры регенерируются: состав файлов цели меняется (нет `.hygen.ts`; dep `@biorate/hygen` сохраняется).

### Modified Capabilities

- `app-generator`: удаляется требование «Доставка фабрики хелперов в сгенерированную цель»; требования «Чистота фабрики хелперов», «Сохранение генерируемого результата (с оговоркой доставки фабрики)» и «Неинтерактивный режим через createPrompter конфига» переписаны без ссылки на доставленный в цель `.hygen.ts`; состав артефактов цели (фикстуры/манифесты) больше не включает `.hygen.ts`.

## Impact

- `_templates/create/root/$ROOT$/.hygen.ts.t` — удалён.
- `_templates/create/root/$ROOT$/package.json.t` — удалён dep `@biorate/hygen` (предположение, на ревью).
- `.hygen.ts` — без изменений (остаётся конфигом генератора репозитория-шаблона).
- `openspec/specs/app-generator/spec.md` — через дельту: −1 требование, 3 переформулированы.
- `AGENTS.md` — строки о доставке фабрики и байт-синхронизации пары файлов.
- `tests/__fixtures__/manifests/` — регенерация (состав и хэши); `tests/factory.spec.ts`/`tests/runner.spec.ts` — проверка на упоминания доставленного файла.
- Обратная совместимость: уже сгенерированные репозитории сохраняют свои `.hygen.ts` (не удаляются и не перетираются); новые цели фабрику больше не получают. Команда генерации и её флаги не меняются.
