# Design

## Context

Генерация всегда запускается из репозитория-шаблона: резолвер конфига движка ищет `.hygen.{js,cjs,mjs,ts}` от cwd вверх, поэтому единственный используемый экземпляр фабрики — корневой `.hygen.ts` этого репозитория. Действие `root` дополнительно доставляет его копию в цель (`_templates/create/root/$ROOT$/.hygen.ts.t`, `mirror: true` + `unless_exists: true`), хотя `_templates/` в цель не доставляется и hygen из цели не запускается. Доставленная копия требует байт-в-байт синхронизации с корневым файлом (sync-тест в `tests/factory.spec.ts:142`). См. proposal.md — Why.

Смежные факты: dep `@biorate/hygen` в `package.json.t` цели сохраняется — через него планируется догенерация шаблонов в сгенерированном репозитории. Golden-фикстуры (`tests/__fixtures__/manifests/`) содержат хэш доставленного `.hygen.ts`.

## Goals / Non-Goals

**Goals:**

- Убрать доставку `.hygen.ts` в сгенерированную цель (шаблон, sync-тест, упоминания в манифестах и документации)
- Оставить корневой `.hygen.ts` единственной фабрикой без изменения его контракта (`export const helpers`, `createPrompter`, guard, валидация)

**Non-Goals:**

- Удаление уже доставленных `.hygen.ts` из существующих сгенерированных репозиториев (политика «генераторные артефакты никогда не удаляются»)
- Изменение команды генерации, флагов, params-схемы или hook-файлов действий
- Миграция `a-before.t`/`z-after.t` в хуки (отдельная задача)

## Decisions

1. **Удалить только шаблон доставки, не трогать корневой `.hygen.ts`.** Альтернатива — переиспользовать доставленный файл как что-то ещё — отклонена: у цели нет своих шаблонов, файл нечитаем движком из цели.

2. **Сохранить dep `@biorate/hygen` в `package.json.t` цели.** Через пакет планируется догенерация шаблонов в сгенерированном репозитории, поэтому dep остаётся. Альтернатива — удалить dep вместе с фабрикой как единую «мёртвую нагрузку» — отклонена решением пользователя.

3. **Sync-тест удалить, а не переворачивать.** Тест `root and repo .hygen.ts.t stay in sync` (`tests/factory.spec.ts:142`) проверяет ровно то, что перестаёт существовать; проверка «шаблона нет» покрывается golden-фикстурами (состав файлов цели).

4. **Фикстуры регенерировать штатным механизмом** (`node tests/__fixtures__/generate-manifests.mjs`) — изменение состава цели (.hygen.ts исчез, dep `@biorate/hygen` исчез из корневого package.json) обязывает по правилам репозитория.

## Risks / Trade-offs

- [Уже сгенерированные репозитории останутся с `.hygen.ts` и dep] → Осознанный компромисс: артефакты не удаляются, вреда нет; при желании потребитель убирает вручную.
- [Кто-то рассчитывал редактировать фабрику в цели] → Сценарий не поддерживался движком и ранее (шаблоны не доставлялись); README/AGENTS генератора этого не обещали. Догенерация из цели использует dep `@biorate/hygen` (сохранён) — конфиг для неё будет добавляться потребителем по мере необходимости.
- [Забытые упоминания `.hygen.ts.t` в доке/тестах] → Греп-проход по репозиторию на `hygen.ts.t` и `unless_exists` включён в задачи.

## Migration Plan

Одна ветка: удалить шаблон и dep, поправить тесты/доку, регенерировать фикстуры, `pnpm test`. Откат — revert коммита; существующие цели не затрагиваются ни в одну сторону.

## Open Questions

Нет: допущение об удалении dep снято решением пользователя — dep сохраняется (догенерация шаблонов в цели).
