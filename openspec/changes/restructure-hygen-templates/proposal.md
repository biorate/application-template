# Proposal

## Why

Каталог `_templates/app/create/` содержит 185 EJS-файлов одной плоской кучей с числовыми префиксами (`00000.00_…`), хотя шаблон фактически состоит из трёх независимых частей: root, client, server. Плоская структура скрывает реальную иерархию, требует скрипта перенумерации и не позволяет генерировать части приложения по отдельности. Миграция с `jondot/hygen` на `@biorate/hygen` уже сделана — сейчас удобно привести структуру шаблонов в соответствие с возможностями движка (вложенные каталоги действий, множественные действия в одной команде, расширение `.t`).

## What Changes

- Команда генерации: `hygen app create …` → `hygen create root,client,server …` (пример); допустим вызов любого подмножества действий (`hygen create root`, `hygen create client,server`, …). Флаги `--client/--server` удалены (роль исполняет список действий); `--app-name/--app-description/--cut-examples/--add-web-socket` сохраняются и дополнительно запрашиваются интерактивно при отсутствии.
- Структура `_templates/app/create/` (плоская, 185 файлов с префиксами `NNNNN.MM_`) разбита на `_templates/create/{root,client,server,help}/`; внутри действия файлы лежат «как будто это корень будущего приложения» (например `client/apps/client/webpack.config.js.t`).
- Расширение шаблонов `.ejs.t` → `.t`.
- Числовые префиксы упразднены; упорядочивание — по алфавиту полного пути. Точки входа: `a-before.t` (плейсхолдер pre-checks) в начале и `z-after.t` (prettier --write, chmod husky) в конце действия `root`.
- Конфигурация генерации (`APP_NAME`, `SERVER_NAME`, `ROOT`, флаги, валидация) переезжает из шаблона-файла `00000.00_config.ejs.t` в фабрику хелперов `.hygen.js` — `helpers` становится функцией `(locals, config) => helpers`, шаблоны используют `h.ROOT`, `h.APP_NAME`, `h.CLIENT` и т.д.
- Гейты `h.server()` / `h.client()` в `to:` выпиливаются (~181 использование): действие `client`/`server` само по себе фильтр.
- **BREAKING** Флаги `--client` / `--server` удалены — их роль исполняет сам список действий; `CLIENT`/`SERVER` вычисляются в `.hygen.js` из позиционных аргументов (списка действий).
- Интерактивный ввод параметров через `prompt.js` в каждом действии: недостающие `--app-name`, `--app-description`, `--cut-examples`, `--add-web-socket` запрашиваются enquirer'ом в TTY; переданные флаги не переспрашиваются; в не-интерактивном режиме — валидационная ошибка без промпта.
- **BREAKING** Флаг `--hygen` удалён; условные ветки `HYGEN ? … : …` и вся логика удаления артефактов (`doc/`, `.hygen.js`, `_templates/`, `.scripts/`) вычеркнуты — генераторные артефакты никогда не удаляются; `.hygen.js` пишется в цель безусловно (обновлён под фабрику-хелперов, деп в `package.json` цели — `@biorate/hygen`).
- **BREAKING** `--root` обязателен (в текущем виде опционален с fallback на cwd — in-place рендер исчезает).
- Guard: рендер падает на первом же шаге, если `realpath(--root)` совпадает с корнем репозитория шаблона (защита от затирания шаблона при локальных запусках/тестах).
- Скрипт `.scripts/renumerate-templates.js` удалён за ненадобностью.
- README.md и AGENTS.md переписаны под новые команды и структуру.

## Capabilities

### New Capabilities

- `app-generator`: поведение генератора приложений — команды `create` (действия root/client/server, комбинируемые через запятую), обязательный `--root`, guard против рендера в репозиторий шаблона, конфигурация и валидация через фабрику хелперов `.hygen.js`, фиксированные точки `a-before`/`z-after`, безусловная запись `.hygen.js` в цель и отказ от удаления каких-либо артефактов.

## Impact

- `_templates/app/create/**` — полная реструктуризация: перемещение, переименование расширений, удаление префиксов, правка `to:` и тел (~185 файлов).
- `.hygen.js` — переписан под фабрику хелперов с guard'ом и валидацией.
- Тестовая инфраструктура репо с нуля: `@biorate/vitest` + `@biorate/vitest-spec` (OOP-декораторы, `Spec`), vitest, allure; тесты через embedding API `runner()`.
- `_templates/app/create/00006.00_.hygen.js.ejs.t` (шаблон `.hygen.js` для цели) — обновлён, гейт `h.hygen` убран.
- `.scripts/renumerate-templates.js` — удалён.
- `README.md`, `AGENTS.md` — новые команды генерации.
- Сгенерированные приложения: получают `@biorate/hygen` в deps вместо `hygen 6.2.11` (только при `--server`-конфигурации с `--hygen`; теперь безусловно по месту прежнего гейта).
- Обратная совместимость: потребители команды `hygen app create` должны перейти на `hygen create root,client,server`; флаги `--app-name/--app-description/--cut-examples/--add-web-socket` сохраняются (плюс интерактивный ввод), `--hygen`, `--client`, `--server` удаляются, `--root` становится обязательным.
